# TLA · Thanks, Local Agent

TLA는 한국어로 부탁하면 내 Android 폰과 앱을 조작하는 개인 AI 에이전트입니다. 웹 버전이 없거나 원하는 기능을 앱에서만 제공할 때, TLA가 폰에서 해당 앱을 열고 필요한 화면으로 이동해 작업을 돕습니다.

## 사용 예

- `5분 타이머 맞춰줘`라고 하면 Android 시계 앱에 타이머를 설정합니다.
- `화면 밝기 70%로 설정해 줘`라고 하면 Android 권한과 사용자 확인을 거쳐 밝기를 조정합니다.
- `메모에 우유 추가해 줘`라고 하면 변경 내용을 보여주고, 승인하면 폰에 저장합니다.

다른 앱은 사용자가 허용한 Android 접근성 서비스로 화면을 읽고 버튼을 누르거나 스크롤합니다. 지원 범위는 앱이 제공하는 화면과 컨트롤에 따라 달라집니다. 결제·삭제·약관 동의처럼 중요한 동작이 화면에서 감지되면 사용자 확인을 요청하거나 실행을 멈춥니다. [앱별 검증 범위](docs/mobile-collaboration.md#플립4-실행-가능-범위)

## 현재 진척

2026년 11월 26일 기준으로 `main`에 반영된 내용입니다.

| 영역 | 구현 및 검증 현황 |
| --- | --- |
| 폰에서 실행하는 로컬 에이전트 | 갤럭시 Z 플립4의 비행기 모드에서 로컬 모델로 한국어 메모 요청을 해석하고, 승인 후 저장한 내용을 앱 재시작 뒤 확인했습니다. 타이머와 카메라 열기, 밝기와 미디어 음량 조절 등 Android 기능도 지원합니다. |
| Android 앱 화면 조작 | 플립4의 시험 앱에서 로컬 모델이 출석 버튼을 고르고 승인 뒤 누르는 흐름을 검증했습니다. 실제 앱에서는 지원 범위를 개별 검증하고 있습니다. |
| OAuth로 연결하는 AI 에이전트 | 현재 ChatGPT·Claude 계정 연결은 Windows 작업자를 거쳐 문서 요청을 보내는 형태로 구현돼 있습니다. 연결되지 않은 계정에 대한 안내와 로컬 모델 동작을 검증했습니다. 실계정 승인, 외부 모델 응답, OAuth 모델이 계획한 앱 조작은 검증이 남아 있습니다. |
| Windows 보조 기능 | 같은 Wi-Fi에서 폰이 긴 문서 작업을 Windows 로컬 모델에 맡길 수 있습니다. Windows의 TLA 대화창에서 페어링한 폰에 지시를 보내는 기능도 있습니다. |

## 다음 목표

1. **Android 앱 조작을 안정화합니다.** 웹에서 처리하기 어려운 작업이 있는 앱부터 실제 폰에서 화면 이동, 버튼 조작, 완료 확인을 검증합니다. 화면이 달라지거나 필요한 권한이 없으면 사용자가 이어서 처리할 수 있도록 알려줍니다.
2. **폰에서 OAuth로 AI 서비스에 연결합니다.** 사용자가 연결한 서비스로 복잡한 요청을 해석하고 다음 동작을 계획할 수 있게 합니다. 실행은 폰의 TLA가 담당하며, 외부 서비스에 보낼 화면이나 문서 내용을 사용자가 확인할 수 있도록 합니다.
3. **로컬과 OAuth 경로를 같은 작업으로 비교합니다.** 완료율, 응답 시간, 사용자 개입 횟수를 실기에서 측정하고, 인터넷이 없는 상태에서도 지원되는 로컬 작업을 이어갈 수 있도록 합니다.

## Android에서 시작하기

Windows 개발 환경에서 Android ARM64 모델 실행기와 TLA APK를 빌드한 뒤 Android 폰에 설치합니다. TLA의 **도구 · 설정**에서 GGUF 모델을 가져오고, 다른 앱의 화면을 조작하려면 Android 설정에서 TLA 접근성 서비스를 허용합니다. [Android 빌드와 실기 검증](docs/mobile-collaboration.md#빌드와-검증)
